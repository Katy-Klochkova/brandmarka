# План разработки Brandmarka

## Этап 1. Подготовка (1 день)

- Описать концепцию и MVP.
- Выбрать стек и зафиксировать структуру.
- Подготовить примеры входных данных.

## Этап 2. Бренд-бук и шаблоны (2 дня)

- Создать модуль `core.brand`.
- Создать JSON-схему бренд-бука.
- Подготовить базовые шаблоны визитки и презентации.

## Этап 3. Генераторы (3 дня)

- Генератор визитки с QR-кодом.
- Генератор email-подписи.
- Генератор презентации через Claude API.
- Генератор коммерческого предложения.

## Этап 4. API и веб (2 дня)

- Написать FastAPI-эндпоинты.
- Сделать простой веб-интерфейс: загрузка бренд-бука, формы, скачивание.

## Этап 5. Тестирование и демо (2 дня)

- Проверить генерацию на реальных данных.
- Записать короткое демо использования.
- Подготовить презентацию проекта для Zerocoder.

## Итого: 10 дней

## Что после MVP

- Личный кабинет и роли.
- Библиотека шаблонов.
- Кейсы / портфолио.
- Мультиязычность.
- Интеграция с Telegram-ботом.
