# MVP Brandmarka

## Обязательный функционал

1. **Бренд-бук компании**
   - Логотип, цвета, шрифты.
   - Тон голоса, примеры формулировок.
   - Контактные данные компании.

2. **Визитки сотрудников**
   - Поля: ФИО, должность, телефон, email, Telegram.
   - QR-код vCard.
   - Экспорт PNG и PDF.

3. **Email-подпись**
   - HTML-подпись для почты.
   - Соответствие бренд-буку.

4. **Клиентская презентация**
   - Ввод: название компании клиента, задача, предложение.
   - Автогенерация слайдов по структуре.
   - Экспорт PPTX и PDF.

5. **Коммерческое предложение**
   - Ввод: услуги, цены, сроки, условия.
   - Генерация форматированного документа.
   - Экспорт DOCX и PDF.

## Что НЕ входит в MVP

- Личный кабинет с ролями.
- Интеграции с CRM.
- Библиотека стоковых изображений.
- Мультиязычность.

## Критерий готовности MVP

Маркетолог может зайти, загрузить бренд-бук, ввести данные сотрудника и клиента, получить визитку и презентацию в едином стиле.
