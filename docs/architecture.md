# Архитектура Brandmarka

## Схема потока

```
Пользователь
    ↓
Web UI / CLI
    ↓
FastAPI routes
    ↓
BrandBook (core.brand)
    ↓
Генератор (generators.*)  ← LLM Claude API
    ↓
Шаблон (templates/*)
    ↓
Рендерер (core.renderer)
    ↓
Экспорт (core.exporter)
    ↓
PDF / PPTX / DOCX / PNG / HTML
```

## Слои

1. **Ввод** — формы в вебе или аргументы CLI.
2. **Бизнес-логика** — валидация, выбор шаблона, вызов LLM.
3. **Рендеринг** — генерация файла по шаблону и данным.
4. **Вывод** — сохранение в папку `output/` и отдача пользователю.

## Хранение

- `data/brandbook.json` — текущий бренд-бук.
- `data/projects.json` — список проектов.
- `output/` — сгенерированные файлы.
- `uploads/` — загруженные логотипы и изображения.

## Генерация через LLM

Промпт строится из:
- бренд-бука (цвета, тон);
- типа документа (визитка, презентация, КП);
- входных данных пользователя.

Claude возвращает структурированный контент (заголовки, описания, слайды), который затем вставляется в шаблон.
